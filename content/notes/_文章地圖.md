# 備孕筆記・文章地圖

最後更新：2026-09-24

這份是寫文章的清單，不會出現在網站上（檔名開頭是底線，跟 `_範本.md` 一樣會被略過）。
要寫新文章時：從下面挑一篇 → 複製 `_範本.md` → 檔名用表格裡的「檔名」欄 → 寫完把 `draft: true` 改成 `false`。

## 一、這份地圖的定位：只寫判斷題

茂盛官網（ivftaiwan.tw、ivftaiwan.com）已經把**資訊題**寫滿了：凍卵費用、補助 3.0 怎麼申請、AMH 正常值、精子 DNA 碎片是什麼、ERA 是什麼。這些關鍵字醫院站已經在排名，個人筆記再寫一次，等於自己跟自己搶流量，而且讀者也拿不到新東西。

所以這份地圖只排**判斷題** —— 病人查完資訊之後，真正卡住的那一題：

| 醫院站回答（資訊題） | 你的筆記回答（判斷題） |
| --- | --- |
| ERA 是什麼 | 我到底該不該做 ERA |
| AMH 正常值是多少 | AMH 0.8，我還有多少時間 |
| 補助怎麼申請 | 補助只有六次，我該怎麼分配 |
| 胚胎分級怎麼看 | 報告說全部不正常，接下來怎麼辦 |

判斷題是醫院官網寫不了的（官網不能有立場），但你可以，因為文章掛的是你的名字。
這也正好對應〈我看生殖醫學的方法〉第 01 條：先理解問題，再決定治療。

## 二、優先順序怎麼定

- **P1**：病人每週都在問、網路上答案混亂或被商業內容主導、而且需要一個有立場的醫師來回答。先寫這些。
- **P2**：問題明確但沒那麼急，或需要 P1 的文章先鋪底。
- **P3**：補齊分類用，什麼時候寫都可以。
- **✅**＝已上線　**📝**＝草稿已寫好，等你審完醫學內容、把 `draft: true` 改成 `false`

> **一篇一篇來，文獻要厚。** 一個題目不要硬塞三個主題。每篇開寫前先做一輪深度文獻掃描，筆記留在 `_research/<slug>.md`（不會上線），文章再從筆記裡長出來。原本的〈ERA、免疫治療、PRP〉已拆成三篇。

標 ★ 的是**只有你寫得出來**的題目 —— 涉及你的判斷、你的實驗室、或你手上的工具。這幾篇是整個備孕筆記的門面，值得多花時間。

## 六、寫作風格：避開機器味

這幾項是實際掃出來的痕跡，每一篇寫完都要自己過一遍（詳細版在 `_範本.md` 最後）：

| 檢查 | 標準 |
| --- | --- |
| 破折號 `——` | **0 個。** 要停頓就斷句，要補充就用冒號 |
| 粗體 | 最多 8 處，只標撐得住的數字與結論 |
| 「」 | 只用在真正的引用，不當強調符號 |
| 段落收尾 | 不要每段都來一句對仗工整的金句 |
| 小標 | 不要預告「接下來是最重要的部分」，直接講 |
| 句型 | 長短交錯，不要一連串結構相同的句子 |

〈我該不該做 ERA？〉改寫前後：破折號 11 → 0、粗體 50 → 5、「」27 → 8。已上線的三篇也順手清過了。

## 七、寫每一篇之前的三個提醒

1. **醫療廣告法規。** 不寫成功率保證、不做院所或醫師之間的成功率比較、不寫「最有效」「一定」。判斷題可以有立場，但立場要建立在證據上，不是在承諾上。
2. **每一篇都要有「我的解讀」。** 這一段才是別人抄不走的部分。如果一篇文章刪掉這一段之後和醫院官網沒兩樣，那就不值得發。
3. **引用寫真的。** references 要有作者、期刊、年份；有 PubMed 連結就放。這是「星際觀測站＋備孕筆記」這個組合可信度的來源。
