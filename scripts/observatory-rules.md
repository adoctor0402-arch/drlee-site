## 寫什麼，不寫什麼

**takeaways（三十秒看懂）要寫。** 三到四條，每條一句完整的話，交代研究設計、
樣本數與主要結果。數字要帶效應量與信賴區間，有分母要寫分母，最後一條寫限制。
摘要沒給效應量就寫「摘要未提供效應量」，不要生一個出來。

**「小王子醫師說」不要寫，留給 `says` 空著，腳本會自動放「待補」。**

這一條 2026-10-16 改過。在那之前的規則是要擬一版 AI 草稿，開頭加一行
「⚠️ 以下為 AI 草稿」。改掉的原因：

那個做法要求草稿帶效應量與信賴區間，但摘要裡沒有那些數字的時候，它還是會生出
看起來很專業的內容。2026-10-16 查核時發現 `jecs-house-dust` 那一篇的各組勝算比、
趨勢檢定 p 值、22 個校正變項與 `r = 0.785` 全都對不上任何公開資料，因為那篇
當時只有摘要、全文未公開。`jesee-microcystin` 也有同樣的問題。

空白的「待補」不會騙人。一段漂亮的中文配著錯的信賴區間，要花更多力氣才抓得出來。
解讀由李醫師自己寫，或是他在對話裡請 Claude 一起寫，那時候有人在旁邊看著。

**要加回自動草稿前，請先想清楚誰來為那些數字負責。**

## 查核規則

每一篇都要回原始論文核對，不能只看 Slack 的二手摘要。與原文不一致時採原文，
並在回報時指出差異。

今天踩過的雷，一定要避開：

- **分清楚摘要和全文。** 讀不到全文就明講「全文在付費牆後，以上取自摘要」，
  不要寫「作者承認⋯⋯」這種你無法證實的話。
- **新聞稿不是論文。** 新聞稿常有論文裡沒有的數字。只出現在新聞稿的東西要標明出處。
- **二手科普網站不能當來源。** 連摘要都讀不到的論文，建議不收。
- **利益衝突要查。** 業界出資、作者是公司員工、檢體來自自家產品，都要寫出來。
- **內部驗證不是外部驗證。** 同一批資料隨機切分出來的驗證組，不可以寫成「獨立驗證」。
- **病例對照研究的 AUC 不能當篩檢效能讀。** 病例比例被人為墊高的資料集算出來的數字，
  給不出陽性預測值。
- **關聯不要寫成因果。** 論文自己用因果字眼的時候，中文要比論文更保守。

被擋的網域。不要用 curl 或 python 繞過去，繞不過，而且不該繞：
`nature.com`、`jamanetwork.com`、`fertstert.org`、`pubmed.ncbi.nlm.nih.gov`、NCBI eutils。
`link.springer.com`、`academic.oup.com`、`api.crossref.org`、`api.openalex.org` 通常可讀。
Crossref 的 API 會有出版社自己存的摘要，付費牆論文可以從那裡拿到逐字摘要。

## 怎麼產生檔案

```
cd "$HOME/mnt/茂盛小王子網站/drlee-site" && node scripts/new-paper.mjs '<JSON>'
```

JSON 欄位（2026-10-16 起，舊的 `asks`／`found`／`reading` 三欄已經合併成 `says`，
傳舊欄位會被靜靜丟掉）：

| 欄位 | 內容 |
|---|---|
| `id` | 檔名用。有 PMID 就用 PMID，否則用簡短英文代號如 `ije-single-women-2026` |
| `title` | 中文標題，20 字內，病人看得懂，盡量寫成問句 |
| `titleEn` | 原文標題 |
| `journal` | 期刊 |
| `pubdate` | YYYY-MM-DD |
| `firstAuthor` / `doi` / `url` | 書目 |
| `topic` | 從：不孕症評估、高齡備孕、凍卵・生育保存、試管嬰兒、PGT・胚胎、反覆流產、男性生育力、AI × 生殖醫學、最新研究 擇一 |
| `takeaways` | 三到四條，見上面「寫什麼」 |
| `says` | **不要傳。** 留空，腳本會放「待補」 |
| `sources` | 其他連結 `[{text,url}]`。原始論文那一行會自動產生，不用重複 |

產生前先看 `content/observatory/` 有沒有同名檔案，有就跳過，不要覆蓋。

`draft` 一律保持 `true`。上架是李醫師按過之後的事。

**注意有兩條管線寫進同一個資料夾**：這支腳本用自訂 id 當檔名，
GitHub Action 的 `fetch-papers.mjs` 用 PMID 當檔名。同一篇研究曾經因此被收兩次
（`42567929` 與 `natmed-dnm-art-2026` 是同一篇 Nature Medicine）。
產生前除了比對檔名，也要比對 DOI。
